# 网络估算 v0.2

日期：2026-10-15。基于用户体验反馈调整；这是自定义估算，不是 Cloudflare 官方 AIM 分数。

## 输入与权重

- 延迟 30%：当前对应地址族第一条展示探针的近 2 小时有效样本，使用 70% P50＋30% P95。按 10 ms 向上分档；少于 5 个采样时用当前延迟。
- 探测失败率 20%：使用同一探针窗口的失败比例。保持原协议语义，不把 TCP 探测失败或 TCP 重传当物理丢包。
- 带宽 40%：近 72 小时可取得的 iperf 历史，下载 70%、上传 30%。速度曲线采用对数插值，继续区分 100～2000 Mbps。
- 延迟波动 10%：相邻有效采样延迟绝对差的均值。按真实时间去重，失败、空值及长缺口断开配对，至少需要 5 对。它是分钟级采样波动，不等同 AIM 包级抖动；未补造负载延迟。

各单项都转换为 0～100 后加权。波动样本不足时不填零，按其余 90% 权重归一并显示“暂估”。探测全失败时显示 0 分。离线、测速过期或最新批次失败/缺项时不造分。

## 曲线锚点

| 指标 | 原始值→分数 |
| --- | --- |
| 延迟 ms | 0→100；50→90；100→75；150→60；200→45；300→20；500→0 |
| 失败率 % | 0→100；0.1→98；0.5→90；1→80；2→65；5→35；10→10；20→0 |
| 带宽 Mbps | 0→0；1→10；10→30；50→55；100→65；300→80；1000→95；2000→100 |
| 波动 ms | 0→100；5→95；10→85；20→65；40→35；80→10；150→0 |

除带宽用 log(1+Mbps) 插值外，其余锚点间线性插值；延迟先按 10 ms 分档。高于末端的数值取末端分数。

## 晚高峰

北京时间 20:00（含）～23:00（不含），带宽历史中晚高峰占 70%，其余时段占 30%。每批必须同 run_id、同地址族且上下行完整。先按日和时段求中位数，再跨日求中位数，降低某天大量手动测试的影响。

没有某一时段时，仅按已有时段临时计算，并明确显示缺项；不把日间数据伪装为晚高峰。失败和不完整批次不冒充 0 Mbps，弹窗明确统计未计批次数；最新失败不回退旧成功。完整 no_response 计为对应方向 0 Mbps，且最新无响应限制旧高速数据的影响。

晚高峰权重仅作用于带宽；当前探针窗口的延迟、失败率、波动仍是当前窗口数据。弹窗同时显示各时段样本天数/批数、日汇总速度、计分构成和缺项，不能把混合路径估算当作 deb 同路径完整 AIM。
